Import items from a spreadsheet (admin)


Choose a CSV or Excel file with one row per item. Columns it understands: Item Code, Description or Name, Category, Pieces per carton, Pieces per dozen, price per piece, per dozen and per carton, Cost per piece (or Landed cost per piece), Reorder level. New items are added and existing ones updated. Stock is never changed here. Your own workbook works too: its Item Master sheet is read. If the file has only a price per piece, the dozen and carton prices follow from it.





Import a delivery from a spreadsheet (admin)


Choose a CSV or Excel file with Item Code, Unit (Carton, Dozen or Piece), Quantity and Cost per unit (or Landed cost per carton). A blank cost uses the item's current cost. Date, Reference and Supplier can be columns in the file or filled in here. Your workbook's Stock In sheet works as it is. This adds stock and updates average costs, so check the preview.
